這個網站做什麼

沃克思營運儀表板是內部使用的唯讀檢視工具，讓已獲授權的人用自己的 Google 帳號登入，查看一份既有 Google 試算表中的營運資料。

會存取哪些 Google 資料

  • 您的 Google 帳號 Email：只用來在畫面上顯示目前登入的帳號。
  • Google 試算表唯讀權限（spreadsheets.readonly）：只讀取網站設定中指定的那一份試算表，不會讀取、修改或刪除您其他的檔案。

資料如何處理

  • 資料直接由您的瀏覽器向 Google 讀取並在瀏覽器中計算顯示，網站沒有伺服器，不會把資料傳送或儲存到任何其他地方。
  • 登入憑證只保存在當次瀏覽的記憶體中，關閉或重新整理分頁即失效；不使用 Cookie 或瀏覽器儲存空間保存資料。
  • 不出售、不分享、不用於廣告或任何其他用途。

如何撤銷授權

隨時可以在網站按「登出」，或到 Google 帳戶的第三方存取權設定 移除這個應用程式。

Google API 使用聲明

本網站使用從 Google API 取得的資訊時，遵守 Google API Services User Data Policy，包括其有限使用（Limited Use）規定。
